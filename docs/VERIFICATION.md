## Review and regression checks

A separate reviewer found three issues, all fixed before delivery:

1. Repeated touch history could replay an old tap after an idle interval. A regression test first reproduced the unwanted click, then passed after preserving counter deduplication and establishing a fresh baseline only during real recovery.
2. The CLI could treat ambiguous transport failures as app-stopped and retry a toggle. It now distinguishes an absent listener from a post-connect failure; uncertain commands return an error rather than being retried.
3. A partial socket request could block other commands. Client I/O now runs separately with bounded concurrency and absolute deadlines. A real socket test verifies that a partial client does not block an `off` request.

Other tests cover report checksums and bounds, inactive contacts, contact reordering, tap-versus-scroll behavior, fresh-contact baselines, overlapping holds, balanced release, initial held contacts, configuration validation, file preservation, and single-server ownership.

The initial test attempts exposed local compiler-cache restrictions and Command Line Tools framework/plugin discovery issues. The final test script uses the installed Swift Testing framework and supplies its macro plug-in path when present. The installed toolchain still emits non-fatal missing developer-library search-path warnings and a deprecation warning for its C-string array initializer; they did not prevent compilation or testing.

## Not yet verified

- Live disconnect/reconnect while dragging, sleep/wake, and permission revocation during output.
- Multi-monitor behavior, a second simultaneously connected controller, DS4 revision 1, Intel Macs, or older macOS versions.
- Developer ID signing, Apple notarization, a clean-machine downloaded installation, or App Store review. Only an ad hoc local signature was applied.

These checks remain requirements before broad public compatibility or release claims. Basic Bluetooth mouse functionality is verified on the user's controller; the unperformed scenarios above are not represented as passed.
